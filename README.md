# befit Rezepte

Diese Datei enthält eine einfache öffentliche GitHub Pages-Seite mit:
- Überschrift: `Rezepte befit Woche`
- Beschreibungstext
- PDF-Button
- QR-Code
- responsives Layout

## Wichtige Infos

1. Das PDF ist aktuell noch als Platzhalter hinterlegt.
2. Ersetze in `script.js` die URL `https://example.com/dein-rezept.pdf` durch den echten öffentlichen PDF-Link.
3. Aktiviere in GitHub unter `Settings > Pages` die GitHub Pages-Option für den `main`-Branch.
4. Anschließend ist die Seite öffentlich erreichbar unter:
   `https://bosch-befit.github.io/rezepte-befit-woche/`

## Dateien

- `index.html` – Hauptseite
- `styles.css` – Styling
- `script.js` – PDF-Link
